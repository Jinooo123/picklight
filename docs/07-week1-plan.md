## 5. 风险与降级方案

| 风险 | 症状 | 降级方案 |
| --- | --- | --- |
| uni-app 环境搭不起来 | 编译报错、真机预览白屏 | 24 小时内搞不定就退回原生小程序 + 手动封装请求，页面结构与组件命名不变，契约不受影响 |
| 契约评审吵不出结论 | 会议超时、字段反复改 | 只冻结"路径 + 字段名 + 错误码枚举"，字段类型细节允许 W2 内小改但要 PR 记录 |
| MySQL 环境不一致 | 迁移在别人机器上报错 | 统一用 8.0，脚本里带 `CREATE DATABASE IF NOT EXISTS`；实在不行用 Docker 镜像，命令写进部署文档草稿 |
| 成员本周有考试/课设冲突 | 任务延期 | 周三前在群里报，T-107、T-110 可顺延到 W2 前两天，但契约与骨架不许延 |
| 原型画得过于精细 | 时间全花在画图上 | 线框级别即可（灰块 + 文字），不上配色不上插画，能说清交互就够 |
