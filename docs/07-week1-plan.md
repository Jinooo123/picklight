# 第 1 周冲刺计划（2026-11-21 ~ 11-27）：初步版本

老师要求一周内出初步版本，本周目标不再是"打完地基"，而是**周五能演一条完整链路**。原计划里 W1 的设计工作已经在 11/20 之前完成（契约草稿、库表草图、三端骨架），本周直接把主流程做出来。

## 1. 周五要能演示什么

按这个顺序演，中间不许崩：

1. 打开小程序 → 注册一个新账号 → 自动进入首页
2. 点「发布」→ 选 2 张图 + 写一段文字 → 上传 → 发布成功
3. 回首页 → 看到自己刚发的动态（带图）
4. 点进详情 → 图片能看、正文能读 → 给它打 4 分
5. 换个账号登录 → 能给它打 5 分（验证一人一评、重复评分是覆盖）
6. 打开管理后台 → 登录 → 能看到用户列表

这六步跑通，就是合格的初步版本。
