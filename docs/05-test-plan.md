# 测试计划（按老师模板展开）

版本：V0.1（2026-11-19）。本文件是测试设计，不表示测试已执行。每位成员负责补全自己模块的实际结果和代码/流程证据。

## 1. 测试层次与完成标准

| 层次 | 范围 | 完成标准 |
| --- | --- | --- |
| 单元/白盒 | 服务端核心分支与权限判断 | 关键函数列流程图、控制流图、环形复杂度和独立路径；自动化测试覆盖独立路径 |
| 接口/黑盒 | 登录、上传、动态、检索、评分评论、后台 | 有效与无效等价类、边界值、权限用例全部执行并记录实际结果 |
| 端到端 | 小程序与后台主流程 | 发布、检索、互动、管理操作在演示环境连续通过 |
| 兼容与体验 | 微信开发工具、常见手机尺寸、桌面浏览器 | 不出现主要文字溢出、不可点击控件或无反馈的失败状态 |

## 2. 黑盒用例重点

| 编号 | 功能 | 有效等价类/边界 | 无效等价类/预期 |
| --- | --- | --- | --- |
| BB-01 | 修改密码 | 正确旧密码，8/25 位新密码可修改 | 旧密码错、少于 8 位、超过 25 位被拒绝 |
| BB-02 | 发布动态 | 仅文字、仅图片、仅视频、带标签可发布 | 正文和媒体皆空、超限/不支持文件被拒绝 |
| BB-03 | 日期标签检索 | 单一条件及组合条件返回匹配结果 | 起始日晚于结束日返回参数错误；无结果显示空状态 |
| BB-04 | 评分 | 1、5 分边界，重复评分覆盖原值 | 0、6、非整数、给自己的动态评分被拒绝 |
| BB-05 | 评论 | 正常评论可查看并删除自己的评论 | 未登录、空评论、删除他人评论被拒绝 |
| BB-06 | 管理后台 | 管理员查询、禁用用户和下架动态 | 普通用户调用管理接口返回无权限 |

每条正式用例按老师模板记录：用例名称、测试目的、覆盖范围、预置条件、测试步骤、预期结果、实际结果和说明。测试数据不使用模板中的电影或 Linux 登录示例。

## 3. 白盒分析样例目标

选取“发布动态”服务方法作为白盒分析对象：身份校验、正文/媒体至少一个非空、媒体归属与类型校验、敏感词校验、数据库写入。实现后根据真实代码绘制控制流图，计算 `V(G)=E-N+2`，列出独立路径并设计自动化测试。不要在实现前编造环形复杂度或覆盖率。

## 4. 缺陷记录

缺陷包含复现步骤、环境、预期/实际、截图或日志、严重度、负责人和修复版本。阻断主流程的缺陷须在第 3 周结束前解决；最终演示前重新执行对应回归用例。
