## 3. 项目范围与技术方案

**必做：**用户注册/登录及修改密码；发布、查看、编辑和删除自己的图文视频动态；添加标签并按日期/标签检索；对他人动态评分和评论；管理员查询、禁用或删除用户，查询、下架或删除内容。

**优先加分：**用户使用与活跃统计图、敏感词过滤。好友、视频流处理和大模型处理暂作备选，只在必做功能和测试稳定后决定是否实现。

**初步架构：**微信小程序（uni-app + Vue 3）和管理 Web（Vue 3 + Vite）共用 Spring Boot REST API。业务数据暂定 MySQL 8，开发环境媒体文件使用服务端受控目录。小程序方向已由组内确认；服务端、数据库和管理端组件库属于待第一周评审的建议。

初步数据实体包括用户、动态、媒体、标签、动态标签关联、评分、评论、活跃事件和管理员操作。权限必须在服务端校验；密码使用哈希保存；同一用户对同一动态只保留一条有效评分；删除和下架后的内容不再公开展示。详细字段与 API 见 [系统设计](02-architecture.md)。
