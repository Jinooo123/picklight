# 账号模块原型与用户故事草稿

任务：T-110（欧阳文锦）。按老师「用户故事文档」模板写出账号相关用户故事，附 4 个页面的线框稿。第一周评审会上过稿，记录修改意见后定稿。

## 1. 用户故事（四段式）

### US-账号-01 注册账号

作为游客，我希望用唯一用户名和密码注册，以便获得发布和互动的权限。

**验收条件：**
1. 用户名 3-20 位、密码 8-25 位，两次密码一致才可提交；
2. 用户名重复时提示且不丢失已填内容；
3. 注册成功后进入首页，且已处于登录状态。

优先级：必做　迭代：M2　状态：草稿　处理人：欧阳文锦　需求分类：账号

### US-账号-02 登录

作为已注册用户，我希望用用户名和密码登录，以便使用个人功能。

**验收条件：**
1. 用户名或密码错误时给出可读提示，不泄露账号是否存在；
2. 被禁用账号登录时提示「账号已被禁用」；
3. 登录成功后回到来源页面，登录态在冷启动时仍有效。

优先级：必做　迭代：M2　状态：草稿　处理人：欧阳文锦　需求分类：账号

### US-账号-03 修改密码

作为登录用户，我希望在个人设置里用旧密码换新密码，以便保护账号安全。

**验收条件：**
1. 旧密码验证失败时不修改；
2. 新密码 8-25 位、两次一致才可提交；
3. 修改成功后强制重新登录。

优先级：必做　迭代：M2　状态：草稿　处理人：欧阳文锦　需求分类：账号

### US-账号-04 退出登录

作为登录用户，我希望安全退出，以便在公共设备上保护账号。

**验收条件：**
1. 退出前二次确认；
2. 退出后清除本地登录态并回到登录页。

优先级：必做　迭代：M2　状态：草稿　处理人：欧阳文锦　需求分类：账号

## 3. 四态约定（四个页面通用）

| 状态 | 表现 |
| --- | --- |
| 加载中 | 提交按钮转圈并禁用，防止重复提交 |
| 空数据 | 本模块无列表，个人中心「我的动态」为空时显示引导去发布 |
| 失败可重试 | 红字提示 + 按钮恢复可点，可重试 |
| 正常 | 见各页面线框 |

## 4. 待评审确认

- 账号标识：用户名（本草稿）还是邮箱/手机号？影响注册字段与唯一索引。
- 退出登录是否真的需要二次确认（可能因课程演示繁琐而简化）。
- 冷启动续期时长（token 有效期）由后端 T-404 决定，前端按 401 统一跳登录。
