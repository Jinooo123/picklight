# 任务分解（WBS）

> 本文件由 `scripts/gen_task_docs.py` 生成，请勿直接编辑。改任务请改脚本里的任务数据后重新运行，`docs/tasks.csv` 会同步刷新，可直接导入腾讯文档/Excel 做周会看板。

共 **87 项**任务，合计 **318 人时**；拆分粒度按「一人一到两天可交付」，每项都带可勾选的验收标准。优先级：P0 = 必做主链路，P1 = 必做但可晚一周，P2 = 加分项（不达标不影响验收）。

## 1. 怎么用

1. 只从自己名下的任务开工，开工前确认「依赖」里的编号都已在 `main` 上合并。
2. 一项任务 = 一个分支 `feat/T-101-login-page`，一项任务 = 一个 PR，PR 标题写 `feat(T-101): 登录页与表单校验`。
3. 验收标准就是 PR 的检查清单，逐条勾完才请人评审；评审通过再 squash 合并。
4. 被阻塞超过半天，在群里报编号和卡点，不要自己硬扛。

## 6. 变更方式

- 新增/拆分/删除任务：改 `scripts/gen_task_docs.py` 里的 `TASKS`，运行 `python scripts/gen_task_docs.py`，连同生成的 md 与 csv 一起提 PR。
- 只改进度不改范围：直接在 GitHub Issue 或腾讯文档看板里改状态，不用动本文件。
- 任务与 `docs/01-requirements.md` 的 FR 编号对应关系在验收标准里体现；新增任务必须能指回某个 FR 或明确的工程目标。
