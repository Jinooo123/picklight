## 环境与限制

小程序采用 HBuilderX 项目结构。微信目标验证使用独立临时目录复制当前小程序源码，仅在临时副本增加一个引用五个组件的验证页，使用 `@dcloudio/vite-plugin-uni@3.0.0-alpha-5030720261117001`（Vue 3.4.21、Vite 5.2.8、Node 24.22.1）编译 mp-weixin。仓库没有新增 CLI 依赖、临时页面或路由。

浏览器适配入口编译实际 Vue 组件与 SCSS；rpx 按 375px 设计宽度换算为 px，用于检查样式与交互。页面中的业务数据与文案为临时样例，不连接真实接口。

管理端构建使用原 `vite.config.js`，通过 Vite API 直接加载配置，避免本工具隔离环境中 esbuild 配置加载的父目录权限错误：

```bash
cd apps/admin
node --input-type=module -e "import config from './vite.config.js'; import { build } from 'vite'; await build({ ...config, configFile: false });"
npm test
```

微信目标编译已通过；微信开发者工具的原生 button loading 运行效果和真机 rpx 布局尚未执行，应由接入页面的成员在微信环境补验。T-107 的“三个业务页面复用”由潘宇在该任务中验证，本记录不代表 T-107 已完成。
