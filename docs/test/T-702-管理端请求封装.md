负责人：黄佳佳（GitHub：julie126）

实现基线：`03be034`（2026-11-20 同步的 main）

## 验收映射

| 验收条件 | 实现与验证 |
| --- | --- |
| 统一 baseURL、token 注入、401 跳登录 | `request.js` 读取环境配置；每次读取当前 token；401 清除 token 并保留来源路径；HTTP 回归覆盖动态 token、并发 401 与旧会话迟到响应 |
| 后端 message 直接展示，不出现 code 数字弹窗 | HTTP 失败只展示非空文本 message；数字/缺失 message 用中文兜底；保留原 Axios error 供页面处理 |
| 请求超时有重试提示 | 10 秒默认超时、可配置；超时和断网均有可读提示；不自动重试写请求 |

## 如何复现

```bash
cd apps/admin
npm ci
npm test
npm run build
```

测试用 Node 内置 HTTP server 产生真实响应，覆盖成功 JSON、token 变更、HTTP 400/401/403、并发失效、旧会话迟到响应、公开登录错误、超时、连接中断与取消请求。测试无需数据库、微信环境或真实后端账号。
