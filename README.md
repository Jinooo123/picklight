# 片刻 MOMENT

> 普通日常，也有闪光。

2026-11-26 起重新设计的课程项目。新的有效源码、设计、API 和运行说明均在 **[next/](next/README.md)**。原有 `apps/`、`services/`、`docs/` 的七人分工与周计划保留作历史参考，不再作为新版本的开发依据。

片刻是一款围绕校园日常的多媒体记录社区：主题征集引导创作，图片、视频、文字共同构成时间线，标签与日期帮助找回回忆，评分和评论让记录获得回应。

## 运行新版本

需要 Node.js 24（含内置 SQLite）。无需安装 MySQL、Java 或云服务。

```sh
cd next
npm ci
npm run build
npm run dev
```

访问 http://127.0.0.1:8088 。管理后台访问 http://127.0.0.1:8088/#admin 。首次启动会创建演示账号，并在终端显示随机初始密码；不要把真实账号信息推送到 GitHub。

微信原生小程序：使用微信开发者工具导入 `next/miniprogram`。详细接入、真机地址与验证限制见 [运行说明](next/README.md)。

## 当前交付

- 用户端：注册登录、修改密码、图文/视频/纯文字发布、编辑删除、主题、日期标签检索、评分与评论。
- 管理端：独立权限入口、用户查询禁用删除、内容查询下架删除恢复、评论删除、操作记录、7 日统计图。
- 服务端：真实 HTTP API、SQLite 持久化、随机会话、scrypt 密码哈希、上传签名与大小检查、服务端归属校验、可配置敏感词。
- 额外提供响应式 Web 用户端，便于无微信环境时演示共用 API；它不替代原生小程序。

验证：`cd next && npm test`、`npm run build`。小程序须在开发者工具/真机继续验收，不将源码检查等同于真机通过。
