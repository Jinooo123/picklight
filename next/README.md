# 片刻 · 运行与交付

## 产品

“把日常留给以后”的校园记录社区。主流程：发现主题 → 发布一个片刻 → 标签日期找回 → 评分评论 → 管理员治理。品牌使用深森林绿、浅青柠、留白与简洁的文字卡片。文字内容与影像同等重要，不强迫用户上传图片。

## 环境和启动

Node.js **24**，npm。数据库使用 `node:sqlite`（该版本会打印实验性提示）；项目锁文件固定安装版本。课程单机/局域网演示，不依赖第三方云。

```sh
cd next
npm ci
npm test
npm run build
npm run dev
```

- 用户端：http://127.0.0.1:8088
- 管理后台：http://127.0.0.1:8088/#admin
- 健康检查：http://127.0.0.1:8088/api/health
- 开发热更新：另开终端执行 `npm run web`，使用 http://127.0.0.1:5173（代理 API 到 8088）。
- 首次空库启动创建 `admin`（管理员）、`demo`、`river` 三个演示账号；随机共同初始密码仅在首次启动终端输出。可以在**首次启动前**通过环境变量 `DEMO_PASSWORD` 指定本地演示密码，至少 8 位；不得将密码写进代码或提交。
- 如果已经有数据库，后续启动不会重新生成账号。可以注册普通用户；管理员演示密码应保存好。
- 默认只监听本机。局域网演示可设置 `HOST=0.0.0.0`、`PORT=8088`，仅在受信网络使用；公网应由 HTTPS 反向代理提供服务。

## 原生微信小程序

1. 开发者工具导入 `next/miniprogram`，不需要 npm 构建。当前 `touristappid` 用于本地预览，正式测试替换为自己的 AppID。
2. `miniprogram/app.js` 中的 `globalData.api` 是服务端根地址。开发者工具本机调试使用 `http://127.0.0.1:8088`；真机必须改为电脑的局域网地址或部署后的 HTTPS 域名，手机的 localhost 不是电脑。
3. 启动 API 后依次测试注册、发布、发现、详情、评分评论、我的回忆、编辑删除和改密。需两个普通账号验证评分与评论权限。
4. 开发配置 `urlCheck:false` 只用于本地调试。正式上线必须配置 request/uploadFile/downloadFile 合法 HTTPS 域名，启用域名校验并使用有效 AppID；小程序审核发布由账号所有者完成。
5. 图片上传为 JPEG/PNG ≤10MB；视频为 MP4 ≤30MB，一条内容最多9张图片或1个视频。原生 video / 浏览器 video 播放并支持服务端文件范围请求；未做转码或 HLS，不声称实现视频流加分项。

## 数据、备份、配置

- 运行数据、上传文件位于 `next/data/`，已忽略。账号密码以 scrypt + 随机盐保存，会话只存 SHA-256 摘要，最长7天。
- 停止服务后整体备份 `data/`（数据库和 uploads 一起），恢复时放回相同位置。SQLite WAL 模式不应运行中只复制单个数据库文件。
- 敏感词在 `server/blocked-words.txt`，每行一个；发布、编辑、评论和昵称在后端校验，修改即时生效。内置少量课程演示词，不等于生产级内容审核；可输入“违禁测试词”验证拦截。
- 默认不集成外部大模型，不需要 API Key。主题功能由预置主题驱动；当前后台不包含主题增删页面。
- 用户/内容删除为逻辑删除。禁用、删除用户立即撤销其会话并隐藏公开动态；恢复用户不会恢复旧会话。下架内容的原上传链接也不可公开访问。

## 验证

`npm test` 使用独立临时数据库启动真实 HTTP 服务，覆盖账号会话、改密、越权、发布编辑、标签检索、评分唯一、评论权限、治理、空数据统计、上传和媒体访问。

`npm run build` 编译 Vue 用户端和管理后台。浏览器已检查登录、发布后列表刷新、详情、管理员真实统计和390px移动布局。证据在 `docs/screenshots/`。

**验证限制**：原生小程序目前已验证源码/配置及请求适配器连接真实 API，尚未在微信开发者工具和真机完整运行；MP4 编解码兼容性需用目标设备实际素材验收。没有部署公网服务或发布微信小程序。

## 演示顺序（约 6 分钟）

1. 游客浏览主题、标签与日期筛选。
2. demo 登录，发布一张图片或一段视频和简短故事，选择“收集一束光”。
3. 我的回忆中编辑文字；刷新发现页验证持久化。
4. river 登录，对刚才内容评分两次，确认评分数仍为1，添加评论。
5. 作者不能删除对方评论；评论者可以删除自己的评论。
6. admin 在 `/#admin` 查询内容并下架，用户端和上传链接不可访问，再恢复。
7. 禁用普通用户，验证原令牌失效；查看操作记录与统计图。
8. 发布含测试敏感词的文字，观察提示且没有新记录；用户修改密码后重新登录。

## 结构

```text
server/app.js           API、权限、参数与业务处理
server/schema.sql       幂等建表及索引
server/app.test.js      HTTP集成测试
web/src/App.vue         响应式用户端与管理员工作空间
web/src/style.css       视觉系统与响应式布局
miniprogram/            微信原生小程序（5个页面）
docs/design.md          设计、课程要求对照与状态规则
docs/api.md             API接口说明
```

初版使用模块化单服务便于课程演示。更大规模时再拆分路由服务、引入对象存储和可靠事件投递；目前不把单机实现描述成高并发生产系统。
